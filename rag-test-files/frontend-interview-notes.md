# 前端八股测试文档

## 防抖和节流

防抖是把连续触发合并成最后一次执行，常用于搜索输入框、窗口 resize 后的布局计算。节流是固定时间间隔最多执行一次，常用于滚动监听、拖拽位置同步。

## 浏览器渲染流程

浏览器从 HTML 构建 DOM，从 CSS 构建 CSSOM，然后合成 Render Tree，接着进行 Layout、Paint、Composite。频繁读取布局属性并写入样式，可能触发布局抖动。

## React key 的作用

key 用于帮助 React 在同级列表中识别节点身份。稳定 key 可以减少错误复用，避免输入框状态串位。不要用数组 index 作为会变化列表的 key。

## WebSocket 断线重连

生产环境通常要实现心跳、指数退避重连、消息去重和会话恢复。客户端应该区分主动关闭和异常断开。
