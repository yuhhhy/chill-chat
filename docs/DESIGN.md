# chillAI 样式指导（DESIGN.md）

本文档从 chillAI 界面截图中提炼，作为后续页面、组件、模块开发的视觉与交互参考。
核心气质：**Chill、轻盈、克制**。靠留白和灰阶分层，而不是边框、阴影、色块。

---

## 1. 设计原则

1. **低饱和、高明度**：主色调为带一点冷蓝紫的"灰白"，几乎没有强对比色块。
2. **以留白代替分隔**：模块之间靠间距和背景明度差区分，不画线、不加边框。
3. **大圆角**：所有可交互元素（按钮、卡片、输入框、列表项）一律圆角，且半径偏大。
4. **层级靠"明度差 + 字重 + 颜色冷暖"**，而不是阴影。整个界面应几乎无 box-shadow。
5. **图标极简**：线性、单色、统一描边宽度（约 1.5px），不使用填充图标。
6. **文本即装饰**：唯一的"亮点"是顶部的大号渐变标题，其他地方一律低调。

## 2. 色彩系统

### 2.1 基础色板

| Token | Hex | 用途 |
|---|---|---|
| `--bg-sidebar` | `#EEF1F8` | 左侧导航栏背景（最浅的冷灰蓝） |
| `--bg-canvas` | `#FFFFFF` | 主内容区背景 |
| `--bg-card` | `#EEF1F8` | 卡片、输入框、推荐卡 |
| `--bg-card-hover` | `#E4E9F2` | 卡片悬停态 |
| `--bg-item-active` | `#DCE4F2` | 列表项选中态（如 sidebar 当前会话） |

### 2.2 文本色

| Token | Hex | 用途 |
|---|---|---|
| `--text-primary` | `#1F2330` | 主标题、卡片正文 |
| `--text-secondary` | `#6B7280` | sidebar 普通项、副标题（"How can I help you?" 这种） |
| `--text-tertiary` | `#9AA1B1` | 占位符（"给 chillAI 发送消息"）、分组标题（"Recent"） |
| `--text-accent-blue` | `#3B82F6` | 选中态文字（如当前 New Chat） |

### 2.3 强调色（仅用于标题渐变）

主标题 `hello, chill` 使用从冷到暖的渐变，控制在 2–3 个停止点：

```css
background: linear-gradient(90deg, #4F8BF5 0%, #B85A8C 70%, #C97A5B 100%);
-webkit-background-clip: text;
color: transparent;
```

**注意**：渐变只用于品牌级标题，不要扩散到按钮、图标、链接上，否则会破坏 chill 感。

## 3. 字体

- **英文 / 数字**：系统无衬线优先，建议 `Inter`、`SF Pro`、`-apple-system`。
- **中文**：`PingFang SC`、`Noto Sans SC`，与英文同一字号下视觉对齐。
- **字重**：仅使用 3 档 —— `400` 正文、`500` 列表项、`700` 主标题。中间档不混用。

### 字号阶梯

| 层级 | 字号 | 字重 | 示例 |
|---|---|---|---|
| 品牌主标题 | 48–56px | 700 | `hello, chill` |
| 副标题 | 36–40px | 500 | `How can I help you?` |
| 卡片正文 | 15px | 400 | 推荐卡内容 |
| sidebar 项 | 14px | 400 / 500（选中） | `New Chat`、`什么也别说` |
| 分组标题 | 13px | 400 | `Recent` |
| 占位符 | 14px | 400 | `给 chillAI 发送消息` |

---

## 4. 间距与圆角

### 4.1 圆角

只用 3 档，**不要出现中间值**：

| Token | 值 | 用途 |
|---|---|---|
| `--radius-sm` | `8px` | 小图标按钮、tag |
| `--radius-md` | `16px` | 卡片、输入框、sidebar 列表项 |
| `--radius-pill` | `9999px` | "New Chat" 按钮这类胶囊形按钮 |

### 4.2 间距尺度（8 的倍数）

`4 / 8 / 12 / 16 / 24 / 32 / 48 / 64`，超过 64 直接用 96。

- sidebar 与主内容区之间：无分割线，靠背景色差自然过渡。
- 卡片之间横向间距：`16px`。
- 主标题与推荐卡之间：约 `64px`。
- 输入框距底部：`32px`。

## 5. 组件规范

### 5.1 Sidebar（左侧栏）

- 宽度：`260px` 左右，固定。
- 背景：`--bg-sidebar`。
- 顶部汉堡图标 + `New Chat` 胶囊按钮（白底 / 浅底，无边框，仅 hover 时背景加深一档）。
- 列表项：高度 `40px`，内边距 `12px 16px`，圆角 `16px`。
  - 默认：透明背景 + `--text-primary`。
  - Hover：`--bg-card-hover`。
  - 选中：`--bg-item-active` + 文字 `--text-accent-blue`。
- 分组标题（`Recent`）：上下间距大，字号小，颜色 `--text-tertiary`，**不加任何分割线**。
- 底部 `RAG` / `Setting`：与列表项同款式，图标在文字左侧，间距 `12px`。

### 5.2 顶栏

- 左对齐品牌名 `chillAI` + 小图标（吉祥物头像）。
- 右上角用户头像，圆形。
- **无下边框、无阴影**，与主内容区无缝。

### 5.3 推荐卡（Suggestion Card）

- 尺寸：宽度自适应（4 列等宽），高度约 `200px`。
- 背景：`--bg-card`，圆角 `--radius-md`。
- 内边距：`24px`。
- 内容：顶部一段中文文案（2–3 行），右下角一个线性图标。
- 图标用单色 `--text-secondary`，尺寸 `20px`。
- Hover：背景切到 `--bg-card-hover`，**无位移、无阴影、无 scale**。

### 5.4 输入框

- 宽度撑满内容区减去左右各 `48px` 边距。
- 高度：`56px`，圆角 `--radius-md`。
- 背景：`--bg-card`，无边框。
- 左侧占位符灰色，右侧依次：知识库下拉、附件、麦克风（均为线性图标按钮）。
- Focus：背景不变，仅占位符隐藏。**不加 outline，不加描边**。

### 5.5 按钮

只定义两种：

1. **Pill button**（如 `+ New Chat`）：胶囊形，浅底无边框，hover 时背景加深一档。
2. **Icon button**：纯图标，方形点击区 `36px`，hover 时出现 `--bg-card` 圆角背景。

**没有实心主按钮**。需要强调时用文字颜色 `--text-accent-blue` 代替。

---

## 6. 图标

- 线性、单色、统一描边 `1.5px`、圆角端点。
- 推荐使用 Lucide / Heroicons outline 套件。
- 不使用品牌图标的彩色版本（如 GitHub 全黑、Google 全灰）。
- 尺寸只用 `16 / 20 / 24` 三档。

---

## 7. 动效

整体克制，符合 "chill" 气质：

- 时长：`150ms`（小元素）或 `250ms`（卡片）。
- 缓动：`cubic-bezier(0.4, 0, 0.2, 1)`，即 Material 的 standard easing。
- 只对 `background-color` 和 `color` 做过渡，**不做 transform、scale、translate**。
- 加载状态：用极淡的骨架屏（`--bg-card` 与 `--bg-card-hover` 之间的呼吸），不要 spinner。

---

## 8. 写代码时的检查清单

提交任何新组件前，对照以下清单：

- [ ] 颜色是否只用了 token 里定义的值？没有临时 hex？
- [ ] 圆角是否落在 `8 / 16 / 9999` 三档？
- [ ] 间距是否是 8 的倍数？
- [ ] 是否引入了 `box-shadow`？（默认答案应是"没有"）
- [ ] 是否引入了 `border`？（除了 `input:focus` 这种极少数情况，也应是"没有"）
- [ ] hover 态是否只改变了背景色，没有位移？
- [ ] 文本字重是否只用了 400 / 500 / 700？
- [ ] 渐变是否只出现在品牌主标题？

任何一项打"否"，先停下来想想是不是真的需要破例。
